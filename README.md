# Criminal Face Recognition System (CFCS)

A fully functional web application designed for law enforcement to manage and identify criminals using facial recognition technology.

## 🚀 Tech Stack
- **Backend:** Python (FastAPI, SQLAlchemy)
- **Computer Vision:** OpenCV (Haar Cascades + LBPH Face Recognizer)
- **Database:** SQLite
- **Frontend:** HTML, CSS (Vanilla), JS, SweetAlert2 for notifications

## ✨ Implemented Modules
- **Module 1 & 2:** Admin Login System & Dashboard Analytics
- **Module 3:** Criminal Management (CRUD operations with photo processing)
- **Module 4 & 5:** Face Detection & Recognition via Webcam or File Upload
- **Module 6:** Results & Alerts (Displays instant match results and criminal profile)

## ⚙️ How to Run
1. Double-click `setup.bat` to automatically install dependencies and initialize the database. *(You only need to do this once)*
2. Double-click `run.bat` to start the web server.
3. Open a browser and navigate to `http://localhost:8000`
4. Login using the default credentials:
   - **Username:** `admin`
   - **Password:** `admin123`
